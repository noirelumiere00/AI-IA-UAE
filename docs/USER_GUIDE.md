# AiLa メールサマリー 使い方（営業向け）

毎朝、Slackの **AiLa からのDM** に「📬 メールサマリー」が届きます。**スクロールせず10秒で「今日まず何をやるか」**が分かるように作っています。

## 1. 最初に一度だけ：連携
Slack で AiLa に **`/connect`** と打つ → 出たURLで自分のGoogle（Gmail/カレンダー）を許可 → 「✅ 連携が完了しました」。これで翌朝からサマリーが届きます。
※ 連携は**自分のメールだけ**。AiLaが勝手に送信することはありません（後述）。

## 2. メールサマリーの読み方（上から優先度順）
```
📬 メールサマリー — 6/9(火)

🔔 未返信 ― 今日中に          ← 失注に直結。最優先で見る
  🟡 佐藤様 見積の件 — 3営業日放置（6/5〜）   ← 重要かつ未返信が放置されている

✉️ 要対応メール（3）          ← 今日来た「あなた宛」の要対応
  🔴 *田中部長*（顧客・緊急） 📝下書き ⏰締切
  【本日締切】Q3提案のご確認        ← 件名をタップでGmailが開く
  本日中に最終確認をお願いします。   ← AIの一言要約

📭 一般 17（参考・件数のみ）    ← ニュースレター等は件数だけ（見たい時はGmail）

📅 今日の予定（3件）           ← 時刻が左・予定が右
  10:30  タスク確認
  14:00  ◯◯社MTG
  🗓 終日: 早退
```
- **色の意味**：🔴顧客・緊急 / 🟠プレス / 🟡顧客 / 🟢社内（カテゴリ語も併記）。
- **アイコン**：📝下書きあり ／ ⏰締切あり ／ ⚠️AIが自信なし（要確認）。
- **件名をタップ**するとGmailの該当メールが開きます。

## 3. 未返信リマインドのボタン（🔔の各件）
| ボタン | 何が起きる |
|---|---|
| **✏️ 対応する** | AIが**返信下書きを作成**（Gmailの下書きにも保存）。スレッドに展開され、確認して **[📝編集]→[📤送信]** できる |
| **✅ 対応済み** | リマインドを解除（押し間違えても直後の **[↩取り消す]** で戻せる） |
| **⏰ 後で** | 3日後にまた知らせる |
| **… → 🔕 もう通知しない** | このスレッドは今後通知しない |
- **返信下書きの送信は必ず2段階確認**（[送信]→確認→もう一度確認）。**誤送信は起きません**。
- あなたが**実際に返信すると、リマインドは自動で消えます**。

## 4. 安全について
- AiLaは**下書きを作るだけ**。実際の送信は**あなたが2段確認したときだけ**。
- 見えるのは**自分のメール/カレンダー**だけ（他人のは見えません）。
- 機微な内容に配慮し、**カレンダーの件名を伏せる設定**も可能（管理者に相談）。

## 困ったら
- サマリーが来ない → `/connect` が済んでいるか確認。
- ボタンが反応しない → 数秒待って再度。続くなら管理者へ。
