# AiLa メールサマリー 使い方（営業向け）

毎朝、Slackの **AiLa からのDM** に「📬 メールサマリー」が届きます。**スクロールせず10秒で「今日まず何をやるか」**が分かるように作っています。

## 1. 最初に一度だけ：連携（リンクをタップするだけ）
連携リンクは**2本**あります。**メール用（Google）が必須**、**Slack用（メンション）は任意**です。

**① メール用（Google）― 必須**
管理者がSlackに貼った **連携リンクをタップ** → 自分のGoogle（Gmail/カレンダー）で「**許可**」→ 「✅ 連携が完了しました」。これで翌朝からサマリーが届きます。

**② Slack用（メンション）― 任意・あとからでもOK**
さらに、未返信のSlackメンションも拾いたい人は **2本目の共通リンクもタップ** → 自分のSlackで「**許可**」→ 「✅ 連携が完了しました」。これで自分宛の**未返信メンション**もサマリーに並びます。

- リンクはどちらも**全員共通**ですが、連携されるのは**タップした本人のアカウントだけ**（他人のメール・Slackには一切触れません）。
- 社用アカウント（会社ドメイン）でタップしてください。個人Gmail等は対象外です。
- **Slackは任意・段階導入**です。やらなくても**メールサマリーは普通に届きます**。やると、自分宛の**未返信Slackメンション**も追加で出るようになります。
- うまくいかない時はSlackで AiLa に **`/connect`** と打つと個別リンクが出ます。
※ 連携は**自分のメール／自分宛Slackメンションだけ**。AiLaが勝手に送信・投稿することはありません（後述）。

## 2. メールサマリーの読み方（上から優先度順）
```
📬 メールサマリー — 6/9(火)

🔔 未返信 ― 今日中に          ← 失注に直結。最優先で見る
  🟡 佐藤様 見積の件 — 3営業日放置（6/5〜）   ← 重要かつ未返信が放置されている
  【メンション】〔#案件-A社〕 @tanaka 例の資料の確認お願いできますか？ — 2営業日未返信（6/10〜）  ← Slackで自分が@メンションされたのに未返信のもの

✉️ 要対応メール（3）          ← 今日来た「あなた宛」の要対応
  🔴 *田中部長*（顧客・緊急） 📝下書き ⏰締切
  【本日締切】Q3提案のご確認        ← 件名をタップでGmailが開く
  本日中に最終確認をお願いします。   ← AIの一言要約

📭 一般 17（参考・件数のみ）    ← ニュースレター等は件数だけ（見たい時はGmail）

📅 今日の予定（3件）           ← 時刻が左・予定が右
  10:30  タスク確認
  14:00  ◯◯社MTG
  🗓 終日: 早退
```
- **色の意味**：🔴顧客・緊急 / 🟠プレス / 🟡顧客 / 🟢社内（カテゴリ語も併記）。
- **アイコン**：📝下書きあり ／ ⏰締切あり ／ ⚠️AIが自信なし（要確認）。
- **件名をタップ**するとGmailの該当メールが開きます。

## 3. 未返信リマインドのボタン（🔔の各件）
| ボタン | 何が起きる |
|---|---|
| **対応する** | **メールの場合**：1クリックで**Gmailの該当スレッド**が、AIが作った**全返信の下書き（あなたの署名入り・リッチ書式のHTML）**付きでインラインに開きます。内容を確認して **Gmailで送信** するだけ。<br>**Slackメンションの場合**：1クリックで**Slackの該当メッセージ（permalink）**が開きます（その場で返信できます。**下書きは作りません**） |
| **対応済み** | リマインドを解除（押し間違えても直後の **[↩取り消す]** で戻せる） |
| **後で** | 3日後にまた知らせる |
| **… → もう通知しない** | このスレッドは今後通知しない |
- **対応する**＝下書きを用意するだけ。**送信はあなたがGmailで確認して押したときだけ**。AiLaが勝手に送ることはありません。
- スレッドの**最新メッセージに連なる全返信**（差出人＋宛先全員、自分は除外）。
- あなたが**実際に返信すると、リマインドは自動で消えます**。

## 4. 安全について
- AiLaは**下書きを作るだけ**。実際の送信は**あなたがGmailで確認して押したときだけ**。
- 見えるのは**自分のメール/カレンダー**だけ（他人のは見えません）。
- **Slackは読み取り専用**で、見えるのは**自分宛のメンションだけ**（他人のSlackは一切見えません）。
- AiLaが**Slackに投稿することはありません**（メンションは「あなたが該当メッセージを開く」だけ）。
- 機微な内容に配慮し、**カレンダーの件名を伏せる設定**も可能（管理者に相談）。

## 困ったら
- サマリーが来ない → `/connect` が済んでいるか確認。
- ボタンが反応しない → 数秒待って再度。続くなら管理者へ。
